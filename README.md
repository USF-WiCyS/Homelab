# Homelab

Today is the day!!! 🤭 In preparation for today’s Homelab workshop, we ask that you come prepared by installing three software on your system:


- VMWare Workstation/Fusion (Mac)
- Docker Desktop
- Splunk Enterprise
**Installing in advance will us get you more hands on experience with setting up the required tools to build out this lab. Do not worry if you don’t have time to install beforehand, we will help you! **
Use the instruction below 👇🏾 

**1. Check Your System**
Determine how much RAM and how many CPU cores your laptop has.
Identify whether your processor is Intel/AMD x64 or Apple Silicon ARM64.

**2. Install Virtualization Software**
Windows/Linux: Install VMware Workstation Pro.
Intel Mac: Install VMware Fusion Pro. 
Apple Silicon Mac: Install VMware Fusion Pro and UTM.
Link to VMWare Workstation Pro: https://support.broadcom.com/group/ecx/productdownloads?subfamily=VMware%20Workstation%20Pro&freeDownloads=true
Link to VMWare Fusion: https://support.broadcom.com/group/ecx/productdownloads?subfamily=VMware%20Fusion&freeDownloads=true

**3. Download and Install the Operating Systems**
Download the Windows Server 2025 x64 ISO (e.g., using the 180-day Evaluation).https://www.microsoft.com/en-us/evalcenter/download-windows-server-2025
Download the Windows 11 Enterprise or Pro ISO (e.g., using the 90-day Evaluation for Enterprise). Apple Silicon users will need the ARM64 version.https://info.microsoft.com/ww-landing-windows-11-enterprise.html
Complete the basic installation of both before the workshop
◦ Windows/Linux/Intel Mac: Install both in VMware.
◦ Apple Silicon Mac: Install Windows 11 ARM64 in VMware Fusion and Windows Server x64 in UTM.

**4. Install/Download Additional Software**
Install Docker Desktop.https://www.docker.com/products/docker-desktop/
Download the free trial of Splunk Enterprise.
